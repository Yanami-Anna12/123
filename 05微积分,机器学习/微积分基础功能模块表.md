# 人工智能微积分基础功能模块表

| 功能模块 | 功能点 | 功能简介 | 功能详情 | 补充说明 |
| --- | --- | --- | --- | --- |
| 导数 | 导数的定义 | 描述函数在某一点处的瞬时变化率 | f'(x₀) = lim(Δx→0) [f(x₀+Δx) − f(x₀)] / Δx | 导数存在则称函数在该点可导 |
| 导数 | 导数的几何意义 | 导数值等于曲线在该点处切线的斜率 | 切线方程：y − f(x₀) = f'(x₀)(x − x₀) | f'>0 函数递增，f'<0 函数递减，f'=0 处曲线平坦 |
| 导数的性质 | 基本初等函数求导 | 掌握常用函数的导数公式 | 常数 (C)'=0；幂函数 (xⁿ)'=nxⁿ⁻¹；(sinx)'=cosx、(cosx)'=−sinx；(eˣ)'=eˣ、(lnx)'=1/x | 机器学习中的激活函数常由这些公式推导导数 |
| 导数的性质 | 四则运算法则 | 对函数进行加减乘除后求导 | (u±v)'=u'±v'；(uv)'=u'v+uv'；(u/v)'=(u'v−uv')/v² | 注意乘积法则与商的法则不要记混 |
| 导数的性质 | 链式法则 | 对复合函数由外向内逐层求导再相乘 | (f(g(x)))' = f'(g(x)) · g'(x) | 神经网络反向传播算法的理论基础 |
| 导数的性质 | 高阶导数 | 对导数继续求导 | 二阶导 f''(x)、三阶导 f'''(x)，记作 d²y/dx² | 用于判断极值类型与函数凹凸性 |
| 极值 | 极值概念 | 函数在某局部范围内的最大值与最小值 | 邻域内 f(x)≤f(x₀) 为极大值，f(x)≥f(x₀) 为极小值 | 极值是局部概念，与全局最值不同 |
| 极值 | 极值的必要条件 | 可导函数的极值点必是驻点 | 若 x₀ 是极值点且函数可导，则必有 f'(x₀)=0 | 反之不成立，如 y=x³ 在 x=0 处导数为 0 却不是极值点 |
| 极值 | 极值的判定与最值求法 | 判断驻点是极大还是极小，并求函数最值 | 一阶导变号法；二阶导 f''(x₀)>0 为极小、<0 为极大；闭区间最值需比较驻点、不可导点与端点处的函数值 | 机器学习中最小化损失函数本质就是求最值问题 |
| 不可微函数 | 不可导的常见情形 | 函数并非处处可导，存在特殊点不可导 | 尖点/角点（如 |x| 在 x=0 处）、函数断点处、切线竖直（斜率无穷大）处均不可导 | 不可导点也可成为极值点候选（如 |x| 在 0 处取极小值） |
| 不可微函数 | 机器学习中的不可微 | 分段线性函数在折点处没有导数 | ReLU(x)=max(0,x) 在 x=0 处不可导 | 实际使用次梯度或单侧导数处理，不影响反向传播与训练 |
| 偏导数 | 偏导数的定义与计算 | 多元函数只对某一个变量求导，其余变量视为常数 | ∂f/∂x = lim(Δx→0) [f(x₀+Δx, y₀) − f(x₀, y₀)] / Δx；求 ∂f/∂y 时把 x 当常数 | 损失函数对每个参数分别求偏导，得到各自更新方向 |
| 偏导数 | 高阶偏导与混合偏导 | 对偏导数再次求偏导 | f_xx、f_yy、f_xy、f_yx 等；二阶混合偏导在连续条件下相等（f_xy=f_yx） | 多元函数二阶信息可判断鞍点或凹凸性 |
| 切平面 | 切平面与线性近似 | 曲面在某点附近可用切平面近似，是偏导数的几何应用 | z = f(x₀,y₀) + f_x(x₀,y₀)(x−x₀) + f_y(x₀,y₀)(y−y₀) | 本质是一阶泰勒展开，多元版本的"切线" |
| 梯度 | 梯度的定义 | 由函数对所有自变量的偏导数构成的向量 | ∇f = (∂f/∂x₁, ∂f/∂x₂, …, ∂f/∂xₙ) | 梯度是标量场的向量，浓缩了各方向变化信息 |
| 梯度 | 梯度的方向与意义 | 梯度指向函数增长最快的方向，负梯度方向下降最快 | 沿梯度方向函数上升最快，沿负梯度方向下降最快；梯度方向垂直于等高线（等值面） | 梯度下降法 θ ← θ − η·∇L(θ) 沿负梯度迭代更新，是机器学习/深度学习优化参数的核心方法 |
