# 机器学习 06-08 学习内容总结表

| 文件 | 学习主题 | 核心内容 | 关键代码 / API | 必记要点 |
| --- | --- | --- | --- | --- |
| 06.自求导的方法实现线性回归.py | 手写梯度下降（双参数） | 用 w、b 两个参数实现 y=wx+b，自己推导均方误差的偏导数，再用学习率乘梯度迭代更新；用 meshgrid 把 w、b 铺成网格逐个算 loss，画出 3D 损失曲面与等高线，并用红线可视化下降路径 | loss_function()、grad_w = mean(2*(y_hat−y)*x)、grad_b = mean(2*(y_hat−y))、np.meshgrid()、plot_surface()、contourf()、GridSpec(2,2)、plt.pause() | 换模型就要重新推一遍导数，无法扩展；path 记录的是更新前的参数，轨迹滞后一步；ax1/ax3 每帧只 scatter 未 cla()，红点会叠加 |
| 07.tensor.py | PyTorch 张量底层（storage / stride / 连续性） | 张量三要素：storage 是底层一维内存、shape 是逻辑形状、stride 是跨步方式；转置后 data_ptr 不变说明数据没搬、只是换了索引方式，此时 view 报错，需 reshape 或 contiguous | .storage().tolist()、.storage().data_ptr()、.stride()、.is_contiguous()、.flatten()、.view()、.reshape()、.contiguous() | view 不复制内存、但要求连续；reshape 遇到不连续会自动拷贝；contiguous 强制拷贝成连续内存；这一节是理解 autograd 的数据基础 |
| 08.基于PyTorch框架的线性回归.py | 用框架实现线性回归（自动求导） | 用 nn.Linear(1,1) 当模型、MSELoss 当损失、SGD 当优化器把 06 重写一遍；训练循环固定五步：前向传播、算 loss、zero_grad、backward、step，手推的导数交给自动微分 | nn.Linear(1,1)、nn.Sequential / nn.ModuleList / nn.ModuleDict、继承 nn.Module 写 forward、nn.MSELoss()、torch.optim.SGD()、torch.manual_seed()、unsqueeze(1) | zero_grad() 必须在 backward() 之前，因为梯度默认累加；x 要 unsqueeze 成 (batch, features) 形状；backward() 就是 06 里手推的那个导数，只是框架自动算了 |

**一句话串联**：06 懂原理 → 07 懂数据怎么存 → 08 会用框架干活（承接 05 单参数手推梯度：05 单参数手推 → 06 双参数手推 + 可视化 → 07 张量底层 → 08 autograd 工程化）。
